Falta justificada — elige el flujo

Las horas no se descontaron. Para mantener el contrato coherente debes elegir cómo se compensa esta clase. Este paso es obligatorio.

Flujo A · Reposición semanal

La clase se repone dentro de la misma semana. La fecha de finalización del paquete no cambia.

Flujo B · Desplazamiento del calendario

No hay reposición esta semana: la fecha proyectada de finalización se recorre automáticamente para conservar las horas contratadas.

Respaldo en la nube

Google Drive · sincronización automática

Configuración (una sola vez, ~5 min):
1. Crea una hoja de cálculo en sheets.new y nómbrala «Registro de clases».
2. Menú Extensiones → Apps Script, borra lo que haya y pega el código del script (descargar código o copiar enlace al archivo). Guarda.
3. Implementar → Nueva implementación → Aplicación web: ejecutar como tú, acceso cualquier persona. Autoriza.
4. Copia la URL /exec y pégala arriba.

Con esto, cada cambio se guarda solo en tu Drive (pestañas «Alumnos» y «Clases» legibles), y puedes usar el panel desde varios dispositivos: en cada uno creas tu PIN, pegas esta misma URL y pulsas «Restaurar desde la nube». La URL es tu llave: no la compartas.
