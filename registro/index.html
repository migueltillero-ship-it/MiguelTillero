Falta justificada — elige el flujo

Las horas no se descontaron. Para mantener el contrato coherente debes elegir cómo se compensa esta clase. Este paso es obligatorio.

Flujo A · Reposición semanal

La clase se repone dentro de la misma semana. La fecha de finalización del paquete no cambia.

Flujo B · Desplazamiento del calendario

No hay reposición esta semana: la fecha proyectada de finalización se recorre automáticamente para conservar las horas contratadas.
