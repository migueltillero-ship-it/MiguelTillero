# Vive el Francés · Miguel Tillero

Plataforma profesional, portafolio y ecosistema educativo de Miguel David Tillero Álvarez, especialista en la enseñanza del francés como lengua extranjera (FLE) y gestor cultural.

## Descripción del Proyecto
Este repositorio aloja el sitio web estático multipágina que centraliza la oferta académica, servicios de traducción, consultoría pedagógica e información institucional del profesor Miguel Tillero.

## Características Técnicas
* **Arquitectura:** Sitio estático multipágina optimizado para SEO.
* **Tecnologías:** HTML5 Semántico, CSS3 (Variables, Mobile-First), JavaScript Vanilla.
* **Rendimiento:** Optimización de carga diferida (Lazy Loading) en recursos multimedia.
* **Integraciones:** EmailJS para el procesamiento de formularios sin backend.
* **Despliegue:** Integración Continua (CI/CD) mediante GitHub Actions hacia GitHub Pages.

## Instalación y Desarrollo
1. Clonar el repositorio localmente.
2. Abrir index.html directamente en un navegador o utilizar una extensión como Live Server.
3. No requiere compilación previa (Build).
